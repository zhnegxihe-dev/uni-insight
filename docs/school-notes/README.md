# 真实的一页

面向高中、本科和研究生的学校真实评价与校园周边推荐页面。

公网地址：

```text
https://zhnegxihe-dev.github.io/uni-insight/school-notes/
```

## 页面定位

- 公开页面只读展示，不开放账号、评论、点赞、私信和公开发帖
- 支持省份、城市、学校、专业组合搜索
- 鼠标滚轮切换学校便签
- 手机端左右滑动切换学校便签，并显示当前位置
- 点击学校查看评价，并可切换查看附近餐厅
- 点击投稿按钮跳转腾讯问卷，由项目方审核后统一更新
- 内容数据集中维护，便于每天或隔天更新

## 更新内容

所有展示内容集中在：

```text
data.js
```

当前 `data.js` 由以下清洗后的基础表生成：

```text
投稿整理_学校名中文_v2.xlsx
```

当前数据合并 `投稿整理_学校名中文_v2.xlsx` 与 `学校和食物.docx`，包含 15 所学校、38 条学生想法和 38 条校外食堂推荐。学校只展示中文名称，不使用英文缩写；学生想法和食堂推荐保留原文。

`index.html` 对样式、数据和脚本使用版本查询参数。更新数据后同时调整版本号，可避免浏览器继续加载旧的 `data.js`。

每个学校包含：

```text

城市
专业
学校摘要
评价便签
附近餐厅
更新时间
来源状态
```

修改后刷新页面即可查看。正式发布时把本目录全部复制到：

## 投稿流程

用户点击“我也想说一句”或左侧“投稿”悬浮条后，直接打开腾讯问卷。管理员收到回答后，统一审核、编辑和匿名化，再更新到 `data.js`。

## 合规边界

- 不开放用户注册和登录
- 不开放实时评论和私信
- 不在公开页直接发布用户内容
- 学校、导师和餐厅内容必须避免无依据指控
- 用户联系方式只在私下核验，不进入公开数据

## 管理员在哪里查看投稿

当前版本是静态页面，**没有后台，也没有统一投稿数据库**。

当前已接入腾讯问卷：

```text
https://wj.qq.com/s2/28008087/ndoo/
```

用户点击“我也想说一句”或左侧“投稿”悬浮条会直接打开该问卷。管理员在腾讯问卷后台的“数据 / 回收”中查看、审核和导出回答。

要集中查看投稿，需要配置一个外部接收端：

1. 腾讯问卷
2. 飞书表单 / 多维表格
3. 金数据
4. 邮箱

在 `data.js` 中填写：

```js
externalFormUrl: "外部表单的公开填写地址",
contactEmail: "管理员接收投稿的邮箱",
```

配置后，投稿页面会出现“打开外部投稿表单”和“邮件发送”按钮。管理员分别到问卷平台的数据管理后台或邮箱中查看、审核和导出内容。

## 响应式布局

电脑端和手机端共用同一个 GitHub Pages 地址。电脑端使用滚轮和层叠便签；手机端自动切换为单张便签、左右滑动、单列阅读、长文折叠和移动端投稿入口。手机端“最近多出来的几张便签”默认显示约 5 行，可点击“展开全文”。
