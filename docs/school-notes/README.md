# 真实的一页

面向高中、本科和研究生的学校真实评价与校园周边推荐页面。

公网地址：

```text
https://zhnegxihe-dev.github.io/uni-insight/school-notes/
```

## 页面定位

- 公开页面只读展示，不开放账号、评论、点赞、私信和公开发帖
- 支持省份、城市、学校、专业组合搜索
- 鼠标滚轮切换学校便签
- 点击学校查看评价，并可切换查看附近餐厅
- 投稿表单在本地生成投稿草稿，由项目方审核后统一更新
- 内容数据集中维护，便于每天或隔天更新

## 投稿流程

当前网页不会直接上传用户内容。

用户填写：

- 学校，必填
- 专业，选填
- 想法，必填
- 好吃的，选填

提交后生成一张可复制的投稿草稿。你收到投稿后，统一审核、编辑和匿名化，再更新到 `data.js`。

如果在 `data.js` 中配置：

```js
externalFormUrl: "https://你的投稿表单地址",
contactEmail: "你的收件邮箱",
```

投稿页会额外显示“打开外部投稿表单”和“邮件发送”按钮；不配置时保持纯静态复制方案。

## 合规边界

- 不开放用户注册和登录
- 不开放实时评论和私信
- 不在公开页直接发布用户内容
- 学校、导师和餐厅内容必须避免无依据指控
- 用户联系方式只在私下核验，不进入公开数据

## 管理员在哪里查看投稿

当前版本是静态页面，**没有后台，也没有统一投稿数据库**。

当前已接入腾讯问卷：

```text
https://wj.qq.com/s2/28008087/ndoo/
```

用户点击“我也想说一句”或左侧“问卷调查”悬浮条会直接打开该问卷。管理员在腾讯问卷后台的“数据 / 回收”中查看、审核和导出回答。

要集中查看投稿，需要配置一个外部接收端：

1. 腾讯问卷
2. 飞书表单 / 多维表格
3. 金数据
4. 邮箱

在 `data.js` 中填写：

```js
externalFormUrl: "外部表单的公开填写地址",
contactEmail: "管理员接收投稿的邮箱",
```

配置后，投稿页面会出现“打开外部投稿表单”和“邮件发送”按钮。管理员分别到问卷平台的数据管理后台或邮箱中查看、审核和导出内容。
